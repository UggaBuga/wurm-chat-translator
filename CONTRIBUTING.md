# Контекст проекта (для разработчиков и ассистентов)

Этот файл — рабочая память проекта. Актуализируется при каждом релизе.
Цель: любой, кто открыл репозиторий (человек или ИИ-ассистент), мог
подхватить разработку без раскопок.

## Что это

**Wurm Chat Translator** — переводчик чатов игры Wurm Online (не мод и не
чит: читает текстовые логи игры из папки `players/<имя>/logs/`). Окно с
вкладками каналов (Local, Trade, GL-Freedom, Event, языковые чаты и др.),
перевод сервисом MyMemory, встроенный словарь игрового сленга, сигналы на
подстроки (звук/уведомление/текст уведомления), «порыться в прошлом»
(история до запуска), автообновление exe с GitHub Releases.

## Структура

- `wurm_chat_gui.py` — весь код приложения одним файлом (~6600 строк).
  Внутри снизу вверх: константы и i18n → утилиты (curl, HTTP) → чтение
  логов и watcher-потоки → `TranslateWorker` → сигналы и звуки →
  автообновление → словари и денежные единицы → GUI → самотест (`--test`).
- `test_*.py` — дым-тесты интерфейса (tkinter): открывают окна, жмут
  кнопки, проверяют поведение. Новой функциональности — новый дым-тест.
- `sounds/` — встроенные wav для сигналов. `curlbin/` — curl.exe для
  автообновления и API.

## Запуск и тесты

```bash
python wurm_chat_gui.py            # приложение
python wurm_chat_gui.py --test     # самотест (должен быть зелёным всегда)
python test_<feature>_gui.py       # каждый дым-тест отдельно
```

## Сборка exe

PyInstaller, onefile, curl и звуки вкладываются ресурсами:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name WurmChatTranslator ^
  --add-binary curlbin;curlbin --add-data sounds;sounds ^
  wurm_chat_gui.py
```

Собранный exe обязан пройти `WurmChatTranslator.exe --test` до публикации.

## Конвенции (менять только согласовав с владельцем)

- **Версии**: `1.7.7.x`, патч-компонент бампится каждый релиз.
- **i18n**: интерфейс на 7 языков — ru, en, pt, de, es, fr, zh. Новый
  строковый ключ добавляется сразу во все семь блоков `I18N` (самотест
  это проверяет). README и интерфейс — на русском и португальском.
- **Релизы**: описание на RU/EN/PT, ассет `WurmChatTranslator.exe`.
  Скриншоты в релиз не кладём (только по личному запросу владельца).
- **Конфиг пользователя** хранится рядом с exe (восстановление галочек
  между сеансами обязательно для новых опций).
- Никаких секретов и машинно-зависимых путей в репозитории.

## Порядок релиза

1. Бамп `APP_VERSION`, реализация, i18n.
2. `python wurm_chat_gui.py --test` + все дым-тесты — зелёные.
3. Сборка exe, самотест exe.
4. Записи в чейнджлог README (RU + PT), актуализация этого файла.
5. Коммит, пуш, GitHub Release (описание RU/EN/PT) + ассет exe.

## Известные грабли

- Антивирус на машине пользователя может съесть DLL при первом запуске
  свежего exe (диалог «Failed to load Python DLL») — повторный запуск
  обычно работает; помощник автообновления перезапускает до 3 раз.
- PowerShell-помощник обновления: ps1 без BOM читается как ANSI и портит
  кириллицу в путях — BOM обязателен.
- Проверка обновлений и API перевода ходят через вложенный curl
  (системный curl — запасной вариант).
